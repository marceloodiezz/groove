# Objetivos del proyecto — Groove

## 1. Introducción

Este documento recoge los objetivos del proyecto **Groove**, una aplicación web orientada al registro, valoración y organización de experiencias musicales.

Groove se desarrollará como un proyecto personal, de manera paralela a los estudios universitarios (Ingeniería Informática del Software).

Su finalidad no será únicamente construir una aplicación funcional, sino también aplicar conocimientos adquiridos durante la carrera, aprender nuevas tecnologías y adquirir experiencia en el desarrollo completo de un producto software.

## 2. Objetivo principal

Diseñar, desarrollar, probar y desplegar una aplicación musical funcional, atractiva y escalable, aplicando los conocimientos adquiridos durante el Grado en Ingeniería Informática del Software y aprendiendo nuevas herramientas mediante su utilización en un proyecto real.

## 3. Objetivos específicos

El desarrollo de Groove perseguirá los siguientes objetivos:

1. Aplicar los principios de análisis, diseño y arquitectura del software.
2. Desarrollar una aplicación web completa mediante tecnologías frontend y backend.
3. Diseñar un modelo de dominio coherente y extensible.
4. Implementar persistencia de datos mediante una base de datos relacional.
5. Integrar APIs externas para obtener información musical.
6. Implementar autenticación, autorización y gestión de usuarios.
7. Desarrollar una interfaz visual moderna y responsive.
8. Aplicar estrategias de pruebas automatizadas.
9. Utilizar herramientas profesionales de control de versiones, integración continua y despliegue.
10. Documentar adecuadamente las decisiones y la evolución del proyecto.
11. Publicar una primera versión que pueda ser utilizada por usuarios reales.
12. Preparar la arquitectura para futuras funcionalidades sociales y aplicaciones móviles.

## 4. Naturaleza y enfoque del desarrollo

Groove será desarrollado como un proyecto personal, de manera paralela a los estudios universitarios.

Por tanto, no se establecerán fechas de entrega ni una dedicación semanal obligatoria.

El trabajo se organizará mediante pequeñas tareas incrementales, que podrán adaptarse a las circunstancias y disponibilidad del desarrollador.

El objetivo no será completar el mayor número posible de funcionalidades en el menor tiempo, sino construir progresivamente un producto estable, mantenible y de calidad.

## 5. Primera meta del proyecto

La primera meta será completar y obtener **Groove v0.1 (MVP)**.

Esta versión deberá ofrecer las funcionalidades esenciales de organización musical personal, centradas en:

- Diario musical de álbumes y EPs.
- Diario de conciertos y experiencias musicales.
- Gestión de colecciones físicas de CDs y vinilos.
- Gestión de usuarios y perfiles personales.
- Búsqueda y consulta de información musical.

La definición detallada de las funcionalidades, sus límites y los criterios de aceptación se encuentra en [Alcance del MVP](alcance-mvp.md).
